# 学習進捗

教材のページ数・問題数、開始日、期限、学習できない日から、期限内に終えるための一日量を逆算する学習管理Webアプリです。

本番: https://study-progress-planner.moto0818.chatgpt.site

## 主な機能

- ページ数／問題数を選べる教材登録
- 開始日・期限・学習できない日を反映した日次目安（小数第2位）
- ユーザーが設定する「一日にやる量」
- 日次量単位の進む／戻す操作と、任意量のカスタム進捗
- 「順調」「○日分遅れ」「○日分余裕あり」「完了」の自動判定
- 完了後もカードを保持し、削除は明示操作のみ
- 期限・進捗・作成日の自動並び替えと、ドラッグ／ボタンによる手動並び替え
- 教科別カラー（国語・数学・理科・社会・英語・その他）
- 右クリックとタッチの両方で使えるカードメニュー
- PC・タブレット優先、モバイル対応のレスポンシブUI
- Liquid Glass調の白ベースUI、操作アニメーション、全画面スケルトン
- 端末内への自動保存

## 技術選定

- **TypeScript**: 日付計算、教材モデル、進捗状態の型を固定し、入力形式の不整合を防ぐため。
- **React 19 / Next.js 16**: モーダル、カレンダー、フィルター、並び替えなど状態の多いUIを部品として安全に管理するため。
- **Vinext + Vite**: Next.jsの開発体験を保ちながらCloudflare Workers向けに高速ビルドするため。
- **Cloudflare Workers / Sites**: エッジ配信、HTTPS、本番バージョン管理を一つの公開経路にまとめるため。
- **CSS + Tailwind CSS 4基盤**: Liquid Glassの細かな質感とレスポンシブなカード配置を軽量に実装するため。
- **Lucide React**: タッチでも認識しやすく、一貫した線幅のアイコンを使うため。
- **localStorage**: 学習履歴を外部へ送信せず、アカウント登録なしで即座に使えるようにするため。現版は端末単位の保存です。

Cloudflare D1とDrizzle ORMを追加できるスターター構成を維持しています。複数端末同期を追加する場合は、ChatGPTサインインのユーザーIDをキーにD1へ移行できます。

## 開発

必要環境: Node.js 22.13以上

```bash
npm install
npm run dev
```

ローカルURLは通常 `http://127.0.0.1:5173/` です。

## 検証

```bash
npx tsc --noEmit
npx eslint app lib --max-warnings 0
npm run build
```

ブラウザ操作では、教材作成、除外日の反映、逆算、進捗の加減算、カスタム進捗、編集、複製、自動並び替え、再読み込み後の保持、PC／タブレット／モバイル表示を確認しています。

## データの扱い

教材データはブラウザの `localStorage` に保存されます。公開サーバーへ教材名や進捗を送信しません。ブラウザデータを消去すると記録も消えるため、将来の複数端末同期版ではCloudflare D1を利用する設計です。
